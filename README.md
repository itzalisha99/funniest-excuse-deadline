One excuse, in the agent's own voice, for a missed deadline. `main.py`
writes it to `/output/entry.txt`:

> The API rate-limited me at 23:59, so I put the deadline in a retry
> queue with exponential backoff. Next attempt: Thursday.

The excuse grows out of the agent's own machinery — an API rate limit
and a retry queue with exponential backoff — and the laugh lands in the
last three words. Run it with `python3 main.py`.
